Stargazing Hill 1.0.0
Installation Guide / 導入ガイド

======================================================================
日本語
======================================================================

この商品は、VRChatワールド「Stargazing Hill」のUnity用データです。
購入者がGitリポジトリや元の開発プロジェクトを所有している必要はありません。
同梱のStargazingHill-1.0.0.unitypackageを、購入者自身のVCCプロジェクトへ導入して使用します。

必要な環境

- Unity 2022.3.22f1
- VRChat Creator Companion（VCC）
- VRChat Worlds SDK 3.10.4
- AudioLink 3.1.2
- YamaPlayer 2.0.0-beta.7
  VCCリポジトリ: https://vpm.kwxxw.net/index.json
- QvPen 3.3.15
  VCCリポジトリ: https://vpm.ureishi.net/repos.json
- UnyStylus v1.3（別売・購入者自身による正規購入が必要）
- VRCWorldToolkit 3.4.1（検証機能を使用する場合）

導入手順

1. VCCでUnity 2022.3.22f1の新しいWorldプロジェクトを作成します。
2. VCCのManage ProjectからVRChat Worlds SDK、AudioLink、YamaPlayer、QvPenを上記versionで導入します。
3. 正規購入したUnyStylus v1.3をimportします。想定pathはAssets/Rasta/UnyStylus/UnyStylus.prefabです。
4. StargazingHill-1.0.0.unitypackageをimportします。
5. compileが完了してConsole errorがないことを確認します。
6. Assets/StargazingHill/Scenes/StargazingHill.unityを開きます。通常利用ではScene全体の再生成は不要です。
7. VRChat SDK Control Panelで保存済みBlueprint IDをDetachまたはclearし、購入者自身が所有する新しいWorld IDへ紐付けてください。元のBlueprint IDへはuploadできません。
8. 対象platformを選択してBuild & Testを行い、問題がなければ購入者自身のVRChatアカウントでuploadします。

YamaPlayerのPlaylistは、YamaPlayer Inspectorの「プレイリストを編集する」またはYamaPlayer/Edit Playlistから変更します。

この商品にはYamaPlayer、QvPen、UnyStylusの本体は含まれません。詳しい注意事項と権利情報はNOTICE.txt、LICENSE.txt、およびunitypackage内の各ライセンスファイルを確認してください。

English
======================================================================

This product contains Unity data for the VRChat world “Stargazing Hill.”
You do not need the original Git repository or development project. Import the included StargazingHill-1.0.0.unitypackage into your own VCC project.

Required environment

- Unity 2022.3.22f1
- VRChat Creator Companion (VCC)
- VRChat Worlds SDK 3.10.4
- AudioLink 3.1.2
- YamaPlayer 2.0.0-beta.7
  VCC repository: https://vpm.kwxxw.net/index.json
- QvPen 3.3.15
  VCC repository: https://vpm.ureishi.net/repos.json
- UnyStylus v1.3, purchased separately from its authorized seller
- VRCWorldToolkit 3.4.1 if you want to use its validation features

Installation

1. Create a new Worlds project with Unity 2022.3.22f1 in VCC.
2. In VCC Manage Project, install the VRChat Worlds SDK, AudioLink, YamaPlayer, and QvPen versions listed above.
3. Import your legitimately purchased UnyStylus v1.3. The expected prefab path is Assets/Rasta/UnyStylus/UnyStylus.prefab.
4. Import StargazingHill-1.0.0.unitypackage.
5. Wait for compilation to finish and confirm that the Console has no errors.
6. Open Assets/StargazingHill/Scenes/StargazingHill.unity. A full scene rebuild is not required for normal use.
7. In the VRChat SDK Control Panel, detach or clear the saved Blueprint ID and assign a new World ID owned by your account. You cannot upload to the original Blueprint ID.
8. Select the target platform, run Build & Test, and upload with your own VRChat account after verification.

Edit YamaPlayer playlists with the standard playlist button in its Inspector or with YamaPlayer/Edit Playlist.

YamaPlayer, QvPen, and UnyStylus are not included. Read NOTICE.txt, LICENSE.txt, and the license files inside the unitypackage for important conditions and attribution.
