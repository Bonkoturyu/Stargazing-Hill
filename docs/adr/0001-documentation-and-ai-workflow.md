# ADR-0001: 文書正本とAI協業方式

- 状態: Accepted
- 決定日: 2026-08-11

## Context

Unityシーン、天文計算、Udon、複数プラットフォーム、第三者素材が同時に関わるため、会話やPR本文だけでは要件、判断、証拠が分散する。複数AIの同時編集はUnity YAMLとGUIDの競合を起こしやすい。

## Decision

- `PROJECT_SPEC.md` と `REAL_SKY_SYSTEM.md` を機能仕様の正本として維持する。
- ADR、テスト、リスク、権利記録を用途別に分け、重複箇所はリンクにする。
- 状態ラベルと情報源の信頼順位を使用する。
- SubAgentは利用者が許可した場合のみ最大1体、深さ1で使い、親が設計・統合・最終検証を保持する。
- シーン/Prefab/Editorの所有者は一人にする。

## Consequences

判断と証拠を追跡しやすくなる一方、実装変更時に関連文書の更新が必要になる。小さな変更ではADRを増やさず、正本またはBACKLOGだけを更新する。
